🧩 ProCalc Chrome Extension

Yes! ProCalc is also an Extension. Install it in Chrome and use calculator from toolbar — without opening website!

How to Install Extension:
1. Download ProCalc-Extension.zip (I gave you below)
2. Unzip it on computer
3. Chrome → chrome://extensions → Developer mode ON → Load unpacked → Select folder
4. Click ProCalc icon on top bar — Calculator opens!

Also works as App: Chrome menu → Install ProCalc
